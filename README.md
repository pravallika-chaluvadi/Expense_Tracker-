# Personal Expense Tracker Using Python

## About the Project

The Personal Expense Tracker is a simple Python application developed to help users manage and track their daily expenses. It allows users to record spending, organize expenses by category, and calculate total expenses.

This project addresses the common problem of losing track of small daily expenses such as food, travel, and shopping.

## Features

- Add new expenses
- Categorize expenses
- View saved expense records
- Calculate total expenses
- Track expenses by category
- Store and retrieve expense data using file handling

## Technologies Used

- **Programming Language:** Python
- **IDE:** Visual Studio Code
- **Concepts:** Lists, Dictionaries, Functions, Loops, Conditional Statements, File Handling

## How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal in VS Code.
5. Run the following command:

```bash
python expense_tracker.py
```

6. Follow the menu options displayed in the terminal.
